📊 How the Value List Works

Official List Notice

The official list states that it is the tier list to use, and warns players not to fully trust other lists or to join any trading server other than the official Bridger trading server. Please read this page as a mirror of that list, not as a second independent source.

Credits: @nh__2 and @gunko_shuri, plus members with the Trading Tierlist Editor role. Last updated: 10/10/2026.

⚖️ What Sets the Value

The list owners state that value is based on stock, demand, hype and future outlook combined — not on current stock alone. A new stand or skin is not automatically pushed to the top just because supply is low.

The value of a stand is not solely its demand number; it is shown by its position on the list. Demand is still taken into account in general, but it is not the primary definer of value.

📈 Stability Tags

Every entry carries a label describing how its value is currently treated: STABLE, HYPED, UNDERPAID, DROPPING, UNSTABLE or HEAVILY UNSTABLE. Some entries combine two labels, such as HYPED/STABLE.

Use the status filter in the full list to find entries that are currently hyped or underpaid.

🔤 Abbreviations

Trades usually move fast and use short codes: FAD4C, UD4C, RTUSK, TSPTW, SPSO and others. The abbreviation column below is the same shorthand used by the list, so you can search a code directly and land on its full skin name, tier and value.
